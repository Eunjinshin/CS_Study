# 10. Interview (면접 대비)

01~09에서 정리한 내용 중 예상 질문 + 본인 답변을 모아두는 폴더.
면접 직전에는 이 폴더만 다시 훑어보는 용도.

## 구조 제안

- `README.md` - 전체 예상 질문 목록 (체크박스로 관리)
- `answers/` - 질문별 답변 정리 (예: `answers/deadlock.md`)

## 예상 질문 예시

- [ ] 프로세스와 스레드의 차이를 설명해주세요
- [ ] TCP와 UDP의 차이는 무엇인가요
- [ ] 인덱스는 왜 조회 성능을 높여주나요
- [ ] SOLID 원칙 중 하나를 실제 코드로 설명해주세요
- [ ] MES가 무엇이고 왜 필요한가요
- [ ] 동시성 문제를 겪어본 경험이 있나요

> 질문은 01~09 폴더에서 실제로 정리한 내용을 기반으로 계속 추가할 것.
