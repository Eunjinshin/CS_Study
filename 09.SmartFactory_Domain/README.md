# 09. Smart Factory Domain (제조 솔루션 도메인 지식)

MES/PLM 등 스마트팩토리 솔루션 회사 지원 시 차별화 포인트가 되는 도메인 지식.
실무에서 MES 프로젝트 진행 중 나온 개념들을 그때그때 정리하는 폴더.

## 학습 체크리스트

- [ ] MES(Manufacturing Execution System)란 무엇인가, 왜 필요한가
- [ ] PLM(Product Lifecycle Management)란 무엇인가, MES와의 관계
- [ ] ISA-95 표준 - 계층 구조 (Level 0~4)
- [ ] ERP - MES - PLC/SCADA 사이의 데이터 흐름
- [ ] OT(Operational Technology) vs IT 차이
- [ ] OPC-UA 프로토콜 기본 개념
- [ ] MQTT 프로토콜 기본 개념 (OPC-UA와 비교)
- [ ] SCADA란 무엇인가, MES와의 역할 차이
- [ ] 생산 실적/설비 가동률 등 MES에서 다루는 핵심 데이터 항목
- [ ] (실무 연결) 지금 진행 중인 MES 프로젝트에서 나온 용어/개념 정리
