# 06. OOP & Design Pattern

- [ ] 디자인 패턴 - 구조 (Adapter, Decorator, Facade)
- [ ] 디자인 패턴 - 행위 (Strategy, Observer, Template Method)

- [ ] Java 관점에서의 인터페이스 vs 추상 클래스
